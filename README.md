# Panda Slang

Бесплатный сайт для понимания китайского интернет-сленга. React + TypeScript + Vite; отдельный сервер, Replit и платные API не требуются.

## Запуск и проверка

Node.js 22.12 или новее:

```
npm ci
npm run dev
npm run typecheck
npm test
npm run build
```

После сборки содержимое dist/ готово к публикации на статическом хостинге. Для Cloudflare Pages: команда npm run build, папка dist. Для загрузки вручную используйте содержимое dist/ (в переносном архиве это website/).

## Где менять сайт

- src/App.tsx — страницы разбора, словаря, избранного и практики.
- src/index.css — оформление и мобильная версия.
- src/data/slang.json — 200 записей, перенесённых из PDF команды.
- public/data/panda-slang-200.json — копия для скачивания; обновлять вместе с основной базой.
- src/slang-engine.ts — поиск и распознавание словарных выражений.
- src/ocr.ts — OCR с прогрессом, отменой и тайм-аутом.
- scripts/prepare-ocr.mjs — копирование движка и языковых моделей для локальной раздачи. Вызывается автоматически при сборке.
- tests/engine.test.mjs — проверки базы и поиска.
- docs/defense.md — сценарий демонстрации, реальные ограничения и план бета-тестирования.

## Данные и ограничения

Сайт использует словарный поиск, без генеративного ИИ. Он не переводит весь текст и не угадывает значения неизвестных слов. Таблица команды перенесена без дополнительной лингвистической валидации. Время на экране измеряет только поиск по словарю.

Скриншоты обрабатываются в браузере через Tesseract.js. Рабочий скрипт, WASM-ядро и модели упрощённого китайского и английского включены в готовую сборку (около 13 МБ суммарно). Первый запуск OCR требует загрузки этих файлов с сайта. Шрифты загружаются из Google Fonts. Произношение зависит от установленных голосов устройства.

Избранное, последние разборы и прогресс хранятся в localStorage этого браузера, без серверной синхронизации. Очистка данных браузера удаляет их. Избранное и разборы можно выгрузить в текстовый файл. Полная база доступна в JSON со страницы словаря.

## Переносимость

Для обычного статического хостинга папка .openai не нужна. Файл public/_redirects настраивает маршруты SPA для совместимых хостингов. На другом хостинге настройте возврат index.html для /dictionary, /saved и /practice.

OCR-ядро и модели распространяются на условиях Apache-2.0. Лицензии находятся в public/ocr/ и включаются в сборку.
